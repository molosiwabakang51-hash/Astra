# Calculator synthesis contract

The original actual model probe gave eight correct computed values but zero strict numeric-only synthesis outputs. The production prompt treated the entire owner question as quoted data, including explicit format instructions. This change promotes a narrow, terminal numeric-only request to an authoritative synthesis instruction outside the quote, but does not promote arbitrary instructions. Reject quote delimiters and multi-line input for this detection. Allow MISMATCH if model interpretation disagrees with the expression. The UI retains model response and exact calculation footer, with warnings for numeric disagreement, incomplete generation and unsupported requested scalar format. The footer remains visible even when a numeric-only response is requested, to avoid concealing that the expression was model-generated and not independently semantically verified. Strict synthesis scoring measures only raw model output, not the entire displayed UI. No rewriting of numeric answers to manufacture credit. Existing unassisted route unchanged. Historical probe can be reproduced with default options; --fresh runs eight supported and four unsuitable newly authored public questions with a different fixed seed. No independent assessment or actual handset result is claimed.
