# Paired self-review evaluation

Twelve new public tasks across logic, quantity, context and strategy. Each begins with actual direct Qwen3 1.7B generation. Both second-pass arms use the same deployed thinking profile, cap 768 and matched seed: one solves afresh, the other gets the actual complete previous visible answer and a candidate revision instruction. Alternate arm order. Incomplete or oversized prior responses cannot enter review; they remain in the fixed denominator. Distinguish strict recovery of wrong scalars, recovery of other strict failures, loss of previously correct answers, paired wins and token/time cost. Noncanonical answers are ungraded for substantive correctness. No answer key or externally computed solution reaches the model, and no model output text is stored in the report. This candidate scalar revision prompt is an experiment, not the existing production prose audit path; no production prompt change or claim of independent factual verification. The comparison controls the second-pass mode, sampling and budget; a gain relative to the original direct answer alone cannot establish a benefit of review. ACIE-055/063/065/115 remain pending broader production and handset evidence.
