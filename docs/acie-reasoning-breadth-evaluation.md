# ACIE breadth comparison: 24 developmental tasks

Motivation: the prior eight-question CPU diagnostic (artifact 15073607086) produced 8/8 standard thinking, 3/8 each direct and decomposed thinking. A single small sample cannot establish general intelligence. This new experiment predefines 24 public synthetic templates, six each in formal/natural logic, quantitative reasoning, contextual interpretation, and constraint/strategy reasoning. Fixed seed 147806239 enables reproduction. Each prompt gets both deployed sampling profiles with the unchanged production system prompt, soft mode switches, and prior diagnostic caps (direct 256, thinking 768). Alternate execution order by case, same per-case seed, no cache reuse, no reference or answer in the inference prompt. The comparison changes the mode, sampling and budget together; it measures configurations, not an isolated causal effect of thinking. CPU inference is not Android JNI. Strict canonical scoring counts incomplete, wrong and noncanonical answers as failures while reporting failure categories separately. Report per-domain denominators and paired outcomes, elapsed time, and tokens. No model reasoning traces, private documents, paid APIs, or score extrapolation. 48 calls total, same bounded workflow. These public developer-authored tasks are not the independent assessment; the 90/100 gate remains unchanged.
