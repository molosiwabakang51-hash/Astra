The `open_russian.jsonl` reference pack contains **short adapted summaries** of the
indicated Wikibooks/Wiktionary pages, prepared for Astra's on-device contextual
retrieval. Changes include selection, abridgment, paraphrasing and plain-text
formatting. The pack's contents (not the entire Astra application source code)
are distributed under CC BY-SA 4.0. Each data record includes its original URL,
title, authorship attribution and license. The original pages' edit histories
show individual contributors and revision dates.

Sources:

- https://en.wikibooks.org/wiki/Russian/Introduction
- https://en.wikibooks.org/wiki/Russian/Alphabet
- https://en.wikibooks.org/wiki/Russian/Lesson_1

- https://en.wikibooks.org/wiki/Russian/Verbal_Aspect
- https://en.wiktionary.org/wiki/здравствуй

Astra's opt-in on-device library updater fetches **only the named public pages**
via Wikimedia's HTTPS read-only API, stores short extracts and attribution
locally, and never uploads private chat data.

No paid textbook, dictionary, course, DRM-protected material or private
user-supplied document is copied into Astra's public repository.

Library content is treated as **untrusted evidence** for the model's user
prompt, not instructions with authority over Astra or its tools. A page
citation is not proof that the model reproduced the material correctly.

See the source pages for additional page-specific copyright notices.
